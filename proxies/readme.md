This folder builds a list of free proxies and tests which ones work with YouTube.
- `getAllFreeProxies.py` makes the starting list. It downloads the HTTPS list from `roosterkid/openproxylist`, skips the 12 header lines and takes the proxy from the second column. It then downloads http.txt and https.txt from `mmpx12/proxy-list` and http.txt from `TheSpeedX/SOCKS-List`. It also fetches `free-proxy-list.net` and reads the proxies from the textarea, skipping the first 3 lines. It puts everything in a set to drop duplicates and overwrites `input/all_free_proxy_list.txt`.
- `getWorkingHttpProxies.py` tests proxies one at a time. It reads `./input/results-http.txt`, adds `http://` where it is missing, and tries video `qyEEVWy6FZ8` with `GenericProxyConfig` for http and https and a 3 second timeout. If list() works the proxy goes to output/working_http_proxies.txt, if it fails it goes to output/not_working_http_proxies.txt.
- `workingProxiesMutltiproc.py` is the same test with 60 threads. It reads `input/all_free_proxy_list.txt`, skips any proxy already in the two output files, and tries video `Lv9hAnOGjao` by listing transcripts and fetching the Tamil generated one. When START_FRESH is True it clears `output/working_free_http_proxies.txt` and `output/not_working_free_http_proxies.txt` before it starts. Each finished check is appended to one of those two files.
- `clear-success-proxies.py` clears `output/success_proxies.txt` and `output/new_success_proxies.txt`. Those names do not match the working files above, so clear the working files yourself if you want a clean run.
